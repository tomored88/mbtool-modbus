mbtool  ·  Modbus master & simulator

Read, write, simulate and analyse Modbus - and design the RS-485 bus - in one program  |  Version 1.0.2  |  Windows 10 / 11

Master and data

Every connection

  • Modbus TCP, RTU and ASCII
  • COM port list, baud / parity / stop bits
  • FC 01-06, 15, 16, 22, 23, 43/14, 17
  • Several programs share one COM port in turn

Live register table

  • Unsigned / Signed / Hex / Binary / Long / Float / Double
  • Address base 0 / 1 / PLC (4xxxx)
  • Multi-type view: several data types side by side
  • Poll tabs: several reads in the main window

Value inspector (F4)

  • One value in every meaning: int, float, text, time, BCD
  • Tries word / byte orders ABCD CDAB BADC DCBA
  • Finds the cause of odd values fast

Device presets (F7)

  • Register maps in JSON: name, unit, scale, data type
  • Library of 30 models: meters, drives, level / pressure / flow
  • Range check before writing, editor, import from CSV

Slave simulator (F9)

  • TCP / RTU / ASCII without real hardware
  • Moving values: random, loop, sine, by device type or preset
  • Fault injection: no reply, slow, CRC, exception, wrong ID ...

Automatic scan

  • Finds baud / parity, Slave IDs and readable addresses
  • Reads the model (FC43 / FC17) and suggests a preset
  • Test Center checks the device against the Modbus rules
Many devices and bus design

Devices window (F11)

  • Many devices at once, one tab each
  • Scan & add: tick the devices found, tabs are created
  • Demo devices: 5 simulated devices to try everything

PLC cycle and calculator

  • Reads every device in turn like a PLC task
  • Measured cycle time, jitter, overruns, line busy %
  • Calculator with baud what-if before you build

Bus health test

  • Real response times per device (avg / p95 / max)
  • Gap sweep: how tightly the line can be polled
  • Recommended timeout and gap - Apply with one click

Error types per device

  • Timeout, CRC, exception, bad frame, wrong ID, no connection
  • Response time and line quality for every device
  • Shown in the device list, device tab and bus map

RS-485 bus map (Ctrl+M)

  • Draw the line: order, cable and stub lengths, terminators
  • Max baud for the length, unit loads, voltage drop
  • Animation of a request and the answer on the wire

Trend, alerts, log

  • Trend graph (F10) of any point
  • Alerts: high / low limits with sound
  • CSV log per device, daily or by size, Excel-ready

Data out, reports and AI

MQTT / database export

  • Every reading to an MQTT broker (JSON or one topic per point)
  • TLS, retain, minimum interval, keeps data while the broker is away
  • SQLite database file - Grafana, Python, Excel

Commissioning report

  • One click: HTML + PDF, English or Thai
  • Devices, error types, response times, values, cycle time
  • Health test, bus map and sign-off boxes

Manual (F1)

  • 85 topics in Thai and English - switch at any time
  • F1 on any field opens its topic
  • Error messages link to 'what does it mean'

Install and use

  • mbtool-setup.exe - installer, choose the folder, no admin rights
  • mbtool-portable.zip - unzip and run, data in one folder (USB stick)
  • No Python needed  ·  mbtool-cli.exe selftest checks the PC in 15 s
Verification status
304 automated tests (34 suites) against simulators and emulated RS-485 lines, plus fault, load and 15-minute soak tests. Not yet tested with real devices: every preset is UNVERIFIED - compare with the device display before writing. The .exe is not code-signed (SmartScreen: More info > Run anyway).
