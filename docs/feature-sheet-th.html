mbtool  ·  Modbus master & simulator

อ่าน เขียน จำลอง วิเคราะห์ Modbus และออกแบบบัส RS-485 ครบในโปรแกรมเดียว  |  เวอร์ชัน 1.0.2  |  Windows 10 / 11

Master และข้อมูล

เชื่อมต่อได้ทุกแบบ

  • Modbus TCP, RTU และ ASCII
  • เลือกพอร์ต COM ตั้ง baud / parity / stop bits
  • FC 01-06, 15, 16, 22, 23, 43/14, 17
  • หลายส่วนในโปรแกรมใช้พอร์ต COM เดียวกันได้ เรียงคิวกัน

ตารางค่าแบบเรียลไทม์

  • Unsigned / Signed / Hex / Binary / Long / Float / Double
  • ฐาน address 0 / 1 / PLC (4xxxx)
  • Multi-type view: ดูหลายชนิดข้อมูลพร้อมกัน
  • แท็บ Poll: อ่านหลายชุดในหน้าต่างหลัก

ตัวตรวจค่า (F4)

  • แปลงค่าเดียวเป็นทุกความหมาย: int, float, ข้อความ, เวลา, BCD
  • ลองลำดับ word / byte ABCD CDAB BADC DCBA
  • หาสาเหตุค่าเพี้ยนได้เร็ว

Preset อุปกรณ์ (F7)

  • แผนที่รีจิสเตอร์ใน JSON: ชื่อ หน่วย scale ชนิดข้อมูล
  • คลังสำเร็จรูป 30 รุ่น: มิเตอร์ ไดรฟ์ level / pressure / flow
  • ตรวจช่วงค่าก่อนเขียน แก้ preset ได้ นำเข้าจาก CSV

Slave จำลอง (F9)

  • TCP / RTU / ASCII ไม่ต้องมีอุปกรณ์จริง
  • ค่าขยับได้: สุ่ม วนลูป sine ตามชนิดอุปกรณ์ หรือตาม preset
  • จำลองความผิดพลาด: ไม่ตอบ ตอบช้า CRC เสีย exception ID ผิด ...

สแกนอัตโนมัติ

  • หา baud / parity, Slave ID และช่วง address ที่อ่านได้
  • อ่านชื่อรุ่น (FC43 / FC17) แล้วแนะนำ preset
  • Test Center ตรวจอุปกรณ์ตามกฎ Modbus
หลายอุปกรณ์ และการออกแบบบัส

หน้าต่าง Devices (F11)

  • อ่านหลายอุปกรณ์พร้อมกัน แยกแท็บละตัว
  • Scan & add: ติ๊กอุปกรณ์ที่เจอ แล้วสร้างแท็บให้
  • Demo devices: อุปกรณ์จำลอง 5 ตัว ลองได้ทุกฟีเจอร์

PLC cycle และเครื่องคำนวณ

  • อ่านทุกอุปกรณ์เรียงกันเหมือน task ของ PLC
  • วัดเวลารอบจริง jitter overrun และ % สายไม่ว่าง
  • คำนวณล่วงหน้า พร้อมตาราง what-if ของ baud

ทดสอบสุขภาพบัส

  • เวลาตอบจริงของแต่ละอุปกรณ์ (เฉลี่ย / p95 / สูงสุด)
  • ไล่ลด gap หาความถี่ที่สายรับได้
  • แนะนำ timeout และ gap กด Apply ได้ทันที

ชนิด error รายอุปกรณ์

  • Timeout, CRC, exception, เฟรมเสีย, ID ผิด, เชื่อมต่อไม่ได้
  • เวลาตอบและคุณภาพสายของทุกอุปกรณ์
  • แสดงในตาราง แท็บอุปกรณ์ และแผนผังบัส

แผนผังบัส RS-485 (Ctrl+M)

  • วาดสาย: ลำดับ ความยาวสาย สายแยก terminator
  • baud สูงสุดตามความยาว unit load แรงดันตก
  • ภาพเคลื่อนไหวคำขอและคำตอบบนสาย

Trend แจ้งเตือน และ log

  • กราฟ Trend (F10) ของจุดไหนก็ได้
  • Alerts: เกณฑ์สูง / ต่ำ พร้อมเสียง
  • Log CSV แยกอุปกรณ์ รายวันหรือตามขนาด เปิดใน Excel ได้

ส่งข้อมูลออก รายงาน และ AI

ส่งข้อมูลออก MQTT / ฐานข้อมูล

  • ส่งทุกค่าไป MQTT broker (JSON หรือแยก topic ต่อจุด)
  • TLS, retain, กำหนดความถี่ เก็บข้อมูลรอเมื่อ broker หลุด
  • ไฟล์ฐานข้อมูล SQLite ใช้กับ Grafana, Python, Excel

รายงานส่งมอบงาน

  • กดครั้งเดียวได้ HTML + PDF ภาษาไทยหรืออังกฤษ
  • อุปกรณ์ ชนิด error เวลาตอบ ค่าที่อ่านได้ เวลารอบ
  • ผลทดสอบสุขภาพบัส แผนผังบัส และช่องลงนาม

คู่มือในโปรแกรม (F1)

  • 85 หัวข้อ ภาษาไทยและอังกฤษ สลับได้ตลอด
  • กด F1 ที่ช่องไหนก็เปิดหัวข้อของช่องนั้น
  • ข้อความ error มีลิงก์ "ความหมายคืออะไร"

ให้ AI ช่วยวิเคราะห์ (F12 AI Assist)

ทางเลือกทำอะไร
แชร์การเชื่อมต่อสดเซิร์ฟเวอร์ MCP ในโปรแกรม ให้ AI อ่านอุปกรณ์ที่ต่ออยู่ มี token อ่านอย่างเดียว
คัดลอกรายงานรายงานวินิจฉัยไปวางใน AI ตัวไหนก็ได้
MCP servermbtool-cli.exe mcp - 34 เครื่องมือ สำหรับ Claude และ AI อื่นที่รองรับ MCP (สแกน อ่าน ทดสอบบัส คำนวณรอบ คู่มือ ...)

ความปลอดภัย: ค่าเริ่มต้นรับเฉพาะเครื่องนี้ ปฏิเสธการเขียนจนกว่าคุณอนุญาต ล็อกเมื่อ token ผิดซ้ำ บันทึกทุกการเรียกใช้

ติดตั้งและใช้งาน

  • mbtool-setup.exe ตัวติดตั้ง เลือกโฟลเดอร์เองได้ ไม่ต้องสิทธิ์ admin
  • mbtool-portable.zip แตกไฟล์แล้วรันได้เลย ข้อมูลอยู่ในโฟลเดอร์เดียว (ใส่ USB ได้)
  • ไม่ต้องมี Python  ·  mbtool-cli.exe selftest ตรวจเครื่องใน 15 วินาที
สถานะการตรวจสอบ
ทดสอบอัตโนมัติ 304 ข้อ (34 ชุด) กับ simulator และสาย RS-485 จำลอง รวมทดสอบความผิดพลาด โหลด และรันยาว 15 นาที ยังไม่ได้ทดสอบกับอุปกรณ์จริง preset ทุกไฟล์ยังเป็น UNVERIFIED ให้เทียบกับหน้าจอเครื่องก่อนเขียนค่า และ .exe ยังไม่ได้ลงนามดิจิทัล (SmartScreen: More info > Run anyway)
